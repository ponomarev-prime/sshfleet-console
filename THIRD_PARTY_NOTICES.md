## Optional companion tools

The official core release archive does not contain the `lf`, `dtop`, Neovim or
`bat` executables and does not contain copied system shared libraries. The
repository only pins their upstream source revisions and provides local build
automation. Their upstream licenses are authoritative:

- `lf`: `tools/src/lf/LICENSE`;
- `dtop`: `tools/src/dtop/LICENSE`;
- Neovim: `tools/src/nvim/LICENSE.txt`;
- `bat`: `tools/src/bat/LICENSE-APACHE`, `LICENSE-MIT` and `NOTICE`.

The locally generated remote workspace bundle is not an official redistributable
release artifact. It can include copied host runtime libraries; anyone who
redistributes that bundle must separately preserve the applicable tool and
system-library licenses and satisfy their source/notice obligations.

## Maintenance

`make test-licenses` compares this inventory and every preserved license hash
against the modules that are actually linked into `./cmd/sshf`. A dependency
upgrade must update this file and the corresponding preserved text in the same
commit.
